# Дневник смен водителя

Небольшое приложение для водителя такси: список поездок за день, сводка
(выручка, комиссия, «на руки», наличные/карта), переключение дней и добавление
поездки с проверкой данных и защитой от дублей.

- **Сервер:** Node.js + TypeScript + Fastify, тесты на vitest.
- **Клиент:** Expo (React Native) + TypeScript + zustand — работает в браузере
  и на телефоне через Expo Go.

> Документ в работе: разделы «Как запустить», «API» и «Решения» будут дополнены.

## Данные

`data/trips.seed.json` — исходный набор поездок за 1–5 октября 2026 года.
Первые две поездки (`t1`, `t2`) взяты из задания без изменений. 4 октября —
выходной, поездок нет. Поездка `t15` начинается 2 октября в 23:40 и
заканчивается 3 октября: на ней видно, к какому дню относится поездка через
полночь.
